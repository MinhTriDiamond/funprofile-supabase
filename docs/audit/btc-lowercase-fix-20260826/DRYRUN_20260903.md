|---|---|---|---|
| angelgiau | 0 | 2026-06-30 12:29 UTC | 36 |
| angelkim | 0 | 2026-07-06 16:59 UTC | 48 |

⚠️ Cả 2 ví đã **im lặng ~2 tháng** trước khi cửa sổ mở. Rủi ro cao là hết 7 ngày vẫn 0 giao dịch mới,
khi đó go/no-go Phase 3 sẽ thiếu đúng phần traffic quan trọng nhất (67/94 dòng mismatch cũ).
Mốc báo cáo sớm: **2026-09-06 03:25 UTC (ngày 3)**.

Query kiểm tra ngày 3:

```sql
select pr.username,
       count(*) filter (where d.created_at > '2026-09-03 03:25:54+00') as new_since_window,
       max(d.created_at) as last_btc
from donations d join profiles pr on pr.id in (d.sender_id, d.recipient_id)
where upper(coalesce(d.token_symbol,'')) = 'BTC'
  and pr.username in ('angelkim','angelgiau')
group by 1;
```
